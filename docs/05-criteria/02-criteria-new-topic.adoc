==== Kriterien für ein neues Thema

Ein neues Thema muss folgende Kriterien erfüllen:

[cols="<2,<1,<7a"]
|===
| Kriterium | Pflicht | Beschreibung

| Originalität
| Muss
| Können Erkenntnisse erzielt werden, die im Bereich der Softwarearchitektur bisher nicht allgemein bekannt sind?

|Relevanz
|Muss
|Ist das Thema für einen größeren Personenkreis interessant?

|Innovation
|Muss
|Bringt das Thema neue Ideen und neues Wissen hervor, das von allgemeinem Interesse ist?

|Kreativität
|Soll
|Zeigt das Thema Kreativität, z. B. durch Synergien, Analogien, Ideen?

|Effektivität
|Soll
|Ist zu erwarten, dass durch die Themenbearbeitung die Arbeit in der Softwarearchitektur zukünftig vereinfacht oder beschleunigt werden kann?

|Problemlösend
|Muss
|Können durch die Themenbearbeitung wiederkehrende und bisher scheinbar unüberwindliche Probleme in der Softwarearchitektur gelöst werden?

Beispiele:

- Kommunikation zwischen Management und Softwarearchitekt:innen verbessern
- Einführung von neuen Methoden, wie z.{nbsp}B. Architekturmanagement, Domain-Driven Design, Green IT, ...

|===

// tag::EN[]
==== Criteria for a New Topic

A new topic must satisfy the following criteria:

[cols="<2,<1,<7a"]
|===
| Criterion | Requirement | Description

|Originality
|Must
| Can new insights be gained that are not yet widely known in the field of software architecture?

Has the topic not yet been completely and publicly addressed (e.g., on Wikipedia)?

|Relevance
|Must
|Is the topic of interest to a larger group of people?

|Innovation
|Must
|Does the topic generate new ideas and knowledge of general interest?

|Creativity
|Shall
|Does the topic demonstrate creativity, e.g., through synergies, analogies, or ideas?

|Effectiveness
|Shall
|Can working on the topic simplify or accelerate future work in software architecture?

|Problem solving
|Must
|Can working on the topic solve recurring and seemingly insurmountable problems in software architecture?

Examples include:

- Improve communication between management and software architects
- Introduction of new methods, such as architecture management, Domain-Driven Design, Green IT, ...

|===
